## 0. 先看这一页

高影响力论文几乎不再把「MedQA 过线」当成临床可用性证据。成熟写法是 **三层分开报**：

1. **公开选择题**：MedQA / MedMCQA / PubMedQA / 中文 CMB、MedBench。测知识覆盖，金标准现成，但和真实诊疗相关度低。
2. **指南/证据接地**：自建临床题 + 医生对照「有 RAG vs 无 RAG」。核心不是准确率单点，而是事实性、完整性、引用是否可核验、幻觉。
3. **病历/对话开放题**：自建 vignette 或真实病历 + **医生量表或逐题 rubric**；若要规模化，先用双标校准 **LLM-as-judge / Boolean 细项**，并报 ICC / κ。

与你们方案的对应：Part 1 对齐第 1 层，但专病题会很少，文献也承认这一点。Part 2 对齐第 2 层，Ferber / Almanac 的对照设计可直接搬。Part 3 对齐第 3 层，不能只报准确率；血液肿瘤专病几乎全是 **几十到三百题的自建库 + 血液科医生盲评**。

**期刊：** 老师提的 *Nature Medicine* 对。并列必查：*Nature*、*NEJM AI*、*JAMA / JAMA Network Open*、*npj Digital Medicine*、*Lancet Digital Health*。专病落地可看 *Blood*、*JCO*，但完整评测框架多半不在专科刊上。

### 2.1 公开题库（对齐 Part 1）



#### #1 Jin 等. MedQA. *Applied Sciences* 2021. IF ≈ 2.5

- **Benchmark：** **新建并公开**。美 / 中国大陆 / 台湾执业考题；英文 12,723 题（测试 1,273），简体 34,251，繁体 14,123。配教材段落语料做检索。
- **指标：** 选项 **Accuracy**；检索侧看证据是否召回。
- **结果 / 首张结果图：** 当时最好模型英文 **36.7%**、繁体 **42.0%**、简体 **70.1%**。文中主图是 OpenQA「检索 + 阅读」流程，数字在结果表。
- **一句话：** 把三国执业考题做成带检索语料的选择题库，只用准确率说明当时系统远未解决医学开放域 QA。

对你们：Part 1 用 MedQA 合法、可复现；原文已写明检索才是瓶颈。淋巴瘤亚组题少，置信区间会宽，和你们「扩到 B 细胞淋巴瘤」的判断一致。

#### #2 Kung 等. ChatGPT × USMLE. *PLOS Digital Health* 2023. IF 较低，引用极高

- **Benchmark：** **现有** 2022 年 USMLE 官方样题，筛选后约 350 题。
- **指标：** Accuracy（不定答计入 / 剔除两套）；解释 concordance；医师 κ。
- **结果 / 首张结果图：** **Fig. 1 是流程图**。**Fig. 2 才是核心结果**：开放题 / 选择题在 Step 1–3 上多在及格线（约 60%）附近。
- **一句话：** 无医学微调的 ChatGPT 在 USMLE 样题上摸到及格，用来证明「能考过」而不是「能看病」。

对你们：这是「考试过线 ≠ 临床可用」叙事的起点。Part 1 可以引用，但不要当主结论。

#### #3 Singhal 等. Med-PaLM. *Nature* 2023. IF ≈ 50

- **Benchmark：** **拼盘公开** MultiMedQA（MedQA、MedMCQA、PubMedQA、MMLU 临床、LiveQA、MedicationQA）+ **自建** HealthSearchQA。
- **指标：** 选择题 Accuracy；长答案医生轴：科学共识、理解、推理、遗漏、伤害、偏见。
- **结果 / 首张结果图：** **Fig. 1 是贡献总图**（基准 + Flan-PaLM 选择题 SOTA + Med-PaLM 人工评）。Flan-PaLM 在 MedQA **67.6%**（当时 +17 个百分点）；长答案上 Med-PaLM 与科学共识对齐 **92.6%**（Flan-PaLM 61.9%），潜在伤害 **5.9% vs 29.7%**。
- **一句话：** 选择题新高仍过不了人工评，所以必须另做多轴医生评估。

对你们：这是把 Part 1 和 Part 3 拆开的经典论据。

#### #4 Singhal 等. Med-PaLM 2. *Nature Medicine* 2025. IF ≈ 58

- **Benchmark：** 公开 MultiMedQA + **自建** 对抗长答案 240 题 + 真实世界医学问题试点。
- **指标：** Accuracy；医生 **9 轴成对偏好**；对抗集各轴显著改善（*P* < 0.001）。
- **结果 / 首张结果图：** **Fig. 1 就是核心结论图**。(a) MedQA **86.5%**；(b) 1,066 条消费者问题上，医生在 9 轴中的 **8 轴更偏好模型**。专科医生相对全科医生答案仍更常赢，但安全性与医生相当；真实问题试点中专科医生 **65%** 更偏好 Med-PaLM 2 而非全科医生答案。
- **一句话：** 选择题接近专家水平之后，主证据改成大规模医生成对比较，并加对抗集。

对你们：Part 3 若要「像顶刊」，优先做 **成对偏好 + 多轴**，不要只打一个总分。

#### #13 Qiu 等. MMed-Llama 3. *Nature Communications* 2024. IF ≈ 15

- **Benchmark：** **新建** MMedBench（6 语种 53,566 QA，测试 8,518）+ **公开** 英 MedQA / MedMCQA / PubMedQA / MMLU-Med。
- **指标：** 选择题 Accuracy；理由生成自动指标 + 人工分。
- **结果 / 首张结果图：** **Fig. 1** 同时给语料、基准构成和 MMedBench 准确率曲线。8B 的 MMed-Llama 3 在开源里领先，英 MedQA **65.4%** 等，接近当时 GPT-4。
- **一句话：** 新增多语言带理由的选择题基准，准确率与理由质量分开报。

对你们：若以后要中英对照，MMedBench 的中文子集比硬译 MedQA 更合适。

### 2.2 评测框架（对总方案）



#### #5 Bedi 等. MedHELM. *Nature Medicine* 2025. IF ≈ 58

- **Benchmark：** **公开拼盘 37 套**，覆盖医生确认的 5 大类 / 22 亚类 / 121 任务；含封闭题与开放任务。
- **指标：** 封闭题 exact match；开放题 **3 模型 LLM-jury**（0–5 量表均值）；成本。Jury 与医生 ICC **0.47**，高于医生–医生 0.43，也高于 ROUGE / BERTScore。
- **结果 / 首张结果图：** **Fig. 1 是框架总图**（分类法 + 基准映射 + 排名/成本）。推理模型 DeepSeek R1、o3-mini **胜率 66%**；Claude 3.5 Sonnet 接近且算力约低 15%。
- **一句话：** 按真实临床任务分类，封闭题自动打、开放题用校准过的 LLM 评审团，并报成本。

对你们：Part 3 若要用模型评分，先做 **jury vs 医生 ICC**，证明不差于医生互评，再扩大规模。

#### #6 Arora 等. HealthBench. arXiv:2505.08775, 2025（预印本，收录理由见文首）

- **Benchmark：** **新建并公开**。5,000 多轮健康对话；262 名医生写 **48,562** 条逐题 rubric。另有 Consensus、Hard 子集。
- **指标：** 按 rubric 加权得分（可负）；主题轴（急救转诊、寻求上下文、全球健康等）；worst-of-n 可靠性。
- **结果 / 首张结果图：** **Fig. 1** 展示「对话 + 医生准则 + 模型评分」一条样本。主结果在后续图：GPT-3.5 **16%** → GPT-4o **32%** → o3 **60%**；Hard 上 o3 仅 **32%**。
- **一句话：** 用医生写的逐对话是否/程度准则打开放对话，不再用选择题代表健康场景。

对你们：Part 3 每题「要点清单」本质就是 HealthBench 的缩小版。优先 **细项是否命中**，而不是 1–5 分笼统印象。

### 2.3 指南 RAG（对齐 Part 2）



#### #7 Zakka 等. Almanac. *NEJM AI* 2024. 无 IF，临床 AI 主场刊

- **Benchmark：** **自建** ClinicalQA。期刊版 **314 题 × 9 专科**；预印本早期为 130 题。
- **指标：** 医生评 **事实性、完整性、偏好、对抗安全**；引用是否可核验。
- **结果 / 首张结果图：** 期刊摘要强调四轴全面优于 ChatGPT-4 / Bing / Bard。预印本 **Fig. 1 是系统图**，**Fig. 2 是核心结果**：事实性平均 **+18 个百分点**（心脏病 91% vs 69%），ChatGPT 引用正确仅 56%；但 ChatGPT 答案仍有 **57%** 被更偏好（可读性）。
- **一句话：** 不考 USMLE，用医生给指南/治疗问答打事实性与引用，并单列对抗安全。

对你们：Part 2 的 Recall/Precision 测「找没找对」；Almanac 说明还要报 **事实性、完整性、引用可核验、安全**。检索对了不等于医生爱用。

#### #8 Ferber 等. 肿瘤指南 RAG. *NEJM AI* 2024

- **Benchmark：** **自建**。胰腺癌 / 转移性结直肠癌 / 肝细胞癌；临床医生出约 **30** 个相关问题；对照 ASCO 与 ESMO。
- **指标：** 两条临床医生把模型陈述与原文指南对照，分正确 / 不准确 / 错误。
- **结果 / 首张结果图：** 公开页以数字为主：**有 RAG 84%**（184/218 正确，30 不准确，4 错）vs **无 RAG 57%**（93/163 正确，29 不准确，41 错）。
- **一句话：** 同一批肿瘤指南问题，只改「是否检索指南」，人工对原文打三分类。

对你们：这是 Part 2 最可抄的对照。你们已有「纯 LLM vs 指南 RAG」。建议陈述级三分类与页面级 P/R **同时报**，避免只报检索 F1。

### 2.4 病历 / 对话 / 医生量表（对齐 Part 3）



#### #9 Tu 等. AMIE. *Nature* 2025. IF ≈ 50

- **Benchmark：** **自建** 159 个 OSCE 场景（加 / 英 / 印），标准化病人；对照 20 名全科医生。
- **指标：** 鉴别诊断 top-1 / top-3；专科医生 32 轴、病人 26 轴（问诊、沟通、共情、处理）。
- **结果 / 首张结果图：** **Fig. 1 是贡献总览**；OSCE 流程在 Fig. 2。专科医生 **30/32 轴**、病人 **25/26 轴** 上 AMIE 优于全科医生。局限：同步文字聊天，不是真实门诊。
- **一句话：** 用双盲 OSCE 把问诊、诊断、沟通、共情一起打，对照真人医生而不是题库。

对你们：Part 3 若有资源，对照「医生」比对照「另一个 LLM」更像顶刊；至少问诊/决策与沟通要分轴。

#### #10 Johri 等. CRAFT-MD. *Nature Medicine* 2025. IF ≈ 58

- **Benchmark：** **改编公开**。2,000 题：MedQA-USMLE 1,800 + 皮肤公开/自建各 100；覆盖 12 专科（含血液肿瘤）。另 100 道 NEJM Image Challenge 给 GPT-4V。
- **指标：** 病例摘要 vs 多轮/单轮/摘要对话下的诊断准确率；选择题与开放题；AI 评分员 + 医生抽查。
- **结果 / 首张结果图：** **Fig. 1 是框架**。**Fig. 2 是核心结果**：多轮对话准确率相对完整 vignette **明显下降**；先摘要再诊断会回升。去掉选项后更差。
- **一句话：** 把考题改成模拟问诊，证明「会做选择题」推不出「会问病史」。

对你们：Part 1 高、Part 3 低并不矛盾。CRAFT-MD 就是这个现象的标准引用。

#### #14 Kanjee 等. GPT-4 × NEJM CPC. *JAMA* 2023. IF ≈ 63

- **Benchmark：** **现有** 70 例 NEJM 临床病理讨论（疑难诊断）。
- **指标：** 首诊是否等于最终诊断；鉴别是否包含最终诊断；Bond 5 分鉴别质量；双人评分 κ。
- **结果 / 首张结果图：** **Figure 即核心结果直方图**：首诊命中 **39%**（27/70），鉴别包含 **64%**（45/70），质量分均值 **4.2/5**（中位数 5）；评分者 κ **0.57**。
- **一句话：** 用公开疑难病例只评鉴别诊断过程，双人打分并报告一致性。

对你们：样本量小但刊高。Part 3 可学：主终点要预先规定（例如「要点是否覆盖」），并报 κ。

#### #15 Goh 等. 医生 ± GPT-4 RCT. *JAMA Network Open* 2024. IF ≈ 10.5

- **Benchmark：** **改编现有** 诊断推理 vignette，每名医生最多 6 例。
- **指标：** **主终点** 结构化反思量表（鉴别准确性、支持/反对依据、下一步检查）；耗时；GPT-4 单独跑分。
- **结果 / 首张结果图：** 流程/主结果图显示：医生+GPT-4 中位 **76%** vs 常规资源 **74%**（校正差 2 个百分点，*P* = 0.60）；GPT-4 **单独** 比只用常规资源的医生高 **16** 个百分点（*P* = 0.03）。
- **一句话：** 随机对照「医生能不能用好模型」，主终点是推理过程量表，不是模型裸分。

对你们：若声称「辅助医生」，必须做人或人机组，不能只报系统准确率。近期做系统评测，把该文当局限讨论即可。

#### #16 Rao 等. PrIME-LLM. *JAMA Network Open* 2026. IF ≈ 10.5

- **Benchmark：** **现有** MSD Manual 29 例，分阶段投喂（症状 → 查体 → 检验影像）。
- **指标：** 五域准确率围成的 **PrIME-LLM 面积**（鉴别、检查、终诊、处理、其他推理）；失败率。
- **结果 / 首张结果图：** 综合分 **0.64–0.78**。终诊多 >90%，但所有模型鉴别失败率 **>80%**。多模态多数更好。
- **一句话：** 不报一个准确率，而报临床路径五域是否均衡。

对你们：Part 3 按抽取 / 分层 / 方案拆开，和这篇同构。总分高、鉴别差，正是要防的。

#### #17 Google. Adaptive Precise Boolean. *npj Digital Medicine* 2026. IF ≈ 12

- **Benchmark：** **自建** 代谢健康（糖尿病、心血管、肥胖）个性化开放题。
- **指标：** Likert vs 细粒度是否题 vs 自适应是否题；**ICC**；耗时；自动打分 F1。
- **结果 / 首张结果图：** **Fig. 1** 对比三类量表：是否题 ICC 明显高于 Likert，自适应后耗时约 **减半**，并仍能标出「缺生物标志物时质量下降」。
- **一句话：** 开放题不要用含糊 Likert，改成可对错的要点是否题，一致性才站得住。

对你们：Part 3 现有「题卡 points」应尽量改成 **是/否要点**，和医生 Likert 并行，先算 ICC。

#### #19 Van Veen 等. 临床摘要. *Nature Medicine* 2024. IF ≈ 58

- **Benchmark：** 放射报告、患者问题、病程、医患对话（现有/公开任务，非 QA 考题）。
- **指标：** 自动 NLP 指标 + **10 名医生** 完整 / 正确 / 简洁；成对偏好；安全/幻觉定性。
- **结果 / 首张结果图：** 前几张多为任务与自动指标；医生研究图显示最佳模型 **36% 更优、45% 相当、19% 不如** 专家摘要。
- **一句话：** 开放生成以医生三轴成对比较为准，ROUGE 只作辅。

对你们：Part 3 不要用 BLEU/ROUGE 当主指标。医生三轴可直接改成「要点覆盖 / 事实错误 / 冗余」。

### 2.5 中文（少量）



#### #11 Cai 等. MedBench. AAAI 2024

- **Benchmark：** **新建公开** 40,041 题：医师资格、住培、主治、真实病例（检查–诊断–治疗）。
- **指标：** 准确率为主。
- **结果 / 首张结果图：** 会议文以表为主：通用 LLM（含 ChatGPT）强于多数中文医学专用模型；中文医学 LLM 在临床知识与诊断精度上仍不足。
- **一句话：** 按中国医师成长路径组中文考题+病例库，用准确率做统一尺子。

对你们：Part 1 中文补题优先用此类 **有官方答案** 的考题，不要自编无金标准选择题。

#### #12 Wang 等. CMB. NAACL 2024

- **Benchmark：** **新建公开**。CMB-Exam 280,839 考题（测试按子类抽 400）；**CMB-Clin 74 例真实病历、208 问**。
- **指标：** 考题 Accuracy；病历开放题 1–5 分（流畅、相关、完整、医学能力）；GPT-4 自动评与专家排序相关。
- **结果 / 首张结果图：** **Fig. 1 是病历题样例**（不是分数图）。**Fig. 2** 为各职业阶段准确率。GPT-4 等过约 **60%** 及格线；**Fig. 3** 显示 GPT-4 自动评与专家排序 Spearman **0.93**。考题高分的中文医学模型在 CMB-Clin 上仍明显落后。
- **一句话：** 中文必须同时报「会不会做题」和「会不会看病历」，后者用量表且可用 GPT-4 代理（先验证相关）。

对你们：这是 Part 1 + Part 3 中文版原型。CMB-Clin 规模（74 例）说明病历基准本来就小。

### 2.6 血液 / 肿瘤专病



#### #18 Laganà 等. 骨髓瘤 HopeAI. *Frontiers in AI* 2025. IF ≈ 3–4（专病完整盲评，故收录）

- **Benchmark：** **自建** 50 个骨髓瘤场景（诊断、分期、治疗、管理），证据截止 2024-06。
- **指标：** 3 名血液肿瘤科医生盲评五维：准确、相关、全面、幻觉、**能否直接用于临床**。报分歧率与 Gwet AC1。
- **结果 / 首张结果图：** **Figure 1** 展示评分者一致性：幻觉判断很一致，**能否直接用** 分歧大（HopeAI 该项分歧 64%，AC1 0.77）。准确率 HopeAI **82.0%** vs 通用模型 48–65%；幻觉普遍低（3–10%）；**临床即用** 最高也只有 **25.3%**。
- **一句话：** 专病自建几十题，血液科盲评五维；准确率高不等于能直接用。

对你们：Part 3 应单列「能否不经修改用于病历场景」。专病评测样本量 50 题在文献里已经算认真。

#### #20 Hwa 等. 真实血液病例. *Blood* 2024;144(Suppl 1):7640. IF ≈ 21（ASH 摘要）

- **Benchmark：** **自建** Primum 平台 107 例真实咨询：淋巴瘤 **30**、骨髓瘤 24、白血病 11、髓系 10、经典血液 32；20 位专家原文 vs GPT-4。
- **指标：** 裁决者偏好；0–4 Likert（质量、实用价值）；能否辨认出 AI。
- **结果 / 首张结果图：** 摘要无独立结果图。专家回答在 **75%** 病例被过半裁决者偏好；质量 2.0 vs 2.1、实用 2.1 vs 2.1（均 *P* = 0.9）；淋巴瘤中 AI 被偏好 **31%**（9/29 量级），多因更短。AI 被正确识别 **90%**。
- **一句话：** 用真实会诊对照专家，质量和实用可以打平，但医生仍更想看个性化专家意见。

对你们：目前最贴近「淋巴瘤真实问答」的高影响力出处，但是 **会议摘要**，细节和第一张图都弱，引用时标明摘要级别。完整方法请以 HopeAI / Almanac / Ferber 为准。

## 3. 跨篇归纳



### 3.1 Benchmark 从哪来


| 类型              | 典型                                                  | 文献                 |
| --------------- | --------------------------------------------------- | ------------------ |
| 公开考题            | MedQA、USMLE 样题、CMB-Exam、MedBench                    | 1–5, 11, 17, 18    |
| 公开拼盘 / 新框架      | MultiMedQA、MedHELM 37 套、HealthBench、MMedBench       | 3–7, 13            |
| 改编公开题           | MedQA → 对话（CRAFT-MD）；诊断考试 vignette                  | 10, 15             |
| 自建（专病/指南几乎全是这种） | ClinicalQA、肿瘤指南 30 问、OSCE 159、骨髓瘤 50、血液 107、代谢健康开放题 | 8–9, 10, 16, 19–20 |


结论：**专病问答没有现成金标准库。** 顶刊也是自建几十到几百题 + 医生评分。公开 MedQA 只适合 Part 1。

### 3.2 指标怎么选


| 任务     | 常用指标                          | 不要单独当主结论    |
| ------ | ----------------------------- | ----------- |
| 选择题    | Accuracy、95% CI               | 过线、SOTA     |
| 指南 RAG | 正确/不准确/错误；事实性；引用可核验；检索 P/R/F1 | 只有生成流畅度     |
| 开放病历   | 要点是否题、多轴 Likert、成对偏好、幻觉率、临床即用 | ROUGE/BLEU  |
| 评分质量   | κ、ICC、Gwet AC1、与医生相关          | 未校准的 LLM 打分 |
| 人机协作   | 过程量表 RCT                      | 模型裸分        |




### 3.3 结果量级（方便写方案时对齐预期）

- 选择题：ChatGPT 约及格 → Med-PaLM 2 MedQA 86.5% → 现模型接近满分，**区分度消失**。
- 指南 RAG：无检索约 55–70%，有检索约 84–97%（Ferber 84%；血液 WHO 指南检索摘要里 GPT-4 可到 97%）。错误从「胡编」变成「不准确」。
- 疑难病例首诊命中可低至 39%，终诊在信息给全后可 >90%，**鉴别阶段仍可失败 >80%**。
- 专病：准确率 80% 仍可能「即用」只有 25%。
- 医生+模型 **不一定** 比医生+UpToDate 更好（Goh）。



### 3.4 第一张图的规律

约一半论文的 **Fig. 1 是框架/样例**，核心数字在 Fig. 2 或表。读文献时不要只截 Fig. 1。本次已标明哪张才是结论图。

## 4. 对 DLBCL-Evidence 方案的具体建议

1. **Part 1 保留 MedQA，但降权。** 文献共识：考题饱和、专病题少。继续报 B 细胞淋巴瘤亚组 + CI；不要把 Acc 当产品主结论。中文少量题用 CMB / MedBench 有官方答案的子集。
2. **Part 2 保持「无 RAG vs 指南 RAG」，并加陈述级三分类。** 与 Ferber 对齐：正确 / 不准确 / 错误。P/R 继续管「页找对没有」；另报引用是否可回指 NCCN/CSCO/EHA。Almanac 说明还要有完整性、负向/对抗题（你们已有「指南未覆盖应拒答」）。
3. **Part 3 把题卡 points 写成 Boolean 要点。** 医生可仍打 1–3 或 1–5，但主统计用要点命中率。双标报 κ/ICC；样本 1 例×10 题只是试点，正式集文献里专病也是 **约 50 题或约 10–30 例病历**。
4. **对照要写进主文。** 最低配：同底座无检索 / 通用 RAG / 专病指南 RAG（Ferber）。若讲辅助决策，才需要 Goh 式人机组。
5. **模型评分可以后置，不能替代首轮医生。** MedHELM、HealthBench、CMB 都是先证明与医生一致再自动化。
6. **主文一句话可用：** 公开考题测知识、指南检索测引用、病历要点测推理；三套分数不合并，专病以自建病历+医生要点分为准。

## 5. 期刊怎么投、怎么读

老师提的 **Nature Medicine** 确实是医学 LLM **评测框架** 的第一选择（Med-PaLM 2、MedHELM、CRAFT-MD、临床摘要医生评都在此）。


| 优先级    | 期刊                                             | 适合什么稿                 |
| ------ | ---------------------------------------------- | --------------------- |
| 必读必引   | *Nature Medicine*                              | 评测框架、长答案医生评、对话推理      |
| 必读     | *Nature*                                       | 系统级里程碑（Med-PaLM、AMIE） |
| 必读     | *NEJM AI*                                      | 指南 RAG、临床场景、医生对照      |
| 必读     | *JAMA* / *JAMA Network Open*                   | 诊断推理、RCT、过程量表         |
| 必读     | *npj Digital Medicine*、*Lancet Digital Health* | 量表方法、数字医学落地           |
| 方法/多语言 | *Nature Communications*、*JAMIA*                | 基准发布、信息学规范            |
| 专病     | *Blood*、*JCO*、*Lancet Oncology*                | 血液/肿瘤病例评测；框架往往仍薄      |
| 中文基准   | AAAI、NAACL、国内医学信息学刊                            | 题库建设；IF 通常不是卖点        |


投稿现实：完整「系统 + 三层评估」更常进 *NEJM AI* / *npj Digital Medicine* / *JAMA Network Open*；*Nature Medicine* 更吃 **新基准或新评分方法**（HealthBench 类、Boolean 量表、LLM-jury 校准）。纯 MedQA 刷分基本不具备这些刊的创新性。

## 6. 检索留档

主式：

```
("large language model*" OR LLM OR "retrieval-augmented generation" OR RAG)
AND (medical OR clinical OR oncolog* OR hematolog*)
AND (evaluat* OR benchmark* OR "question answering" OR chatbot)
AND (accuracy OR recall OR precision OR rubric OR clinician* OR hallucination OR faithfulness)
```

加严：`AND (MedQA OR MedHELM OR HealthBench OR MedBench OR CMB)`；`AND (guideline* OR NCCN OR ESMO) AND RAG`；`AND ("clinical reasoning" OR vignette OR rubric)`。

纳入：2023 及以后（MedQA 2021 例外）；必须有 benchmark、指标、数字；临床医学问答。排除：无评测图/表、纯影像、与问答无关。

未纳入但可备查：Nori 等 GPT-4 USMLE 技术报告（预印本，与 Kung/Med-PaLM 重叠）；WHO 血液指南检索 ASH 2023 摘要（GPT-4 71%→97%）；多发性骨髓瘤以外的 JCO 会议摘要。
