# 五篇精品：问答（QA）系统如何评估


| 项   | 内容 |
| --- | --- |
| 日期  | 2026-09-28 |
| 用途  | 补上一轮调研里「问答论文不够」的缺口；专看 **系统如何答一道问、评测如何打分** |
| 范围  | 3 篇医学 QA（含肿瘤专科 + 医学 RAG），2 篇其他高风险领域 QA（金融、通用 RAG） |
| 年限  | 2021–2025 |
| 预印本 | 本轮不收 |


每篇固定四栏：**benchmark（公开/自建）→ 指标 → 结果（含首张结果图）→ 一句话评估设计**。影响因子为 2024/2025 JCR 约值；ACL / EMNLP 为计算机顶会，不报 IF。

上一轮 20 篇里，不少是考试选择题、OSCE 问诊、鉴别诊断 RCT，任务不等于「一问一答」。本轮只收 **Question → Answer** 评测。

---

## 0. 先看这一页

专科/领域 QA 评得好的论文，几乎都把评估拆成两层，而不是只报一个准确率：

1. **答案对不对**：有金标准就用 Accuracy / Exact Match / 可执行程序对错；没有金标准就用医生量表、成对偏好、或「是否误导」。
2. **答案是不是从证据来的**：检索召回、引用是否对、是否该拒答、证据是否虚构。金融 QA 把第 2 层做成 **可执行推理程序**；通用 RAG 做成 **段落级接地标注**。

和你们系统的对应：

- Part 1（公开题）≈ 第 3 篇 MIRAGE 的选择题 Accuracy。
- Part 2（指南 RAG）≈ 第 3 篇的「语料 × 检索器」对照 + 第 5 篇的接地 / 拒答。
- Part 3（病历开放题）≈ 第 1 篇的医生多轴盲评 + 第 2 篇的 NCCN 对标误导分。
- 老师否定「全是大模型抽题打分」：这五篇里，**金标准都是人写的题或人标的分**；模型只当考生，不当阅卷人（第 5 篇用 LLM-as-judge 时，先有人标好的长答案和段落相关性）。

## 2. 分篇

### #1 Wang 等. LINS. *Nature Communications* 2025. IF ≈ 14–16

- **Benchmark：** **公开 + 自建**。客观题约 15,530 道：公开 6 套（MedMCQA、PubMedQA*、MedQA 美/陆/台、Geneturing-disease）+ **50 名主治自建 Multi-MedCQA**（9 个专科子库共 4,685 题，含 **血液科**，题面不公开答案以防泄漏）。开放题：HealthSearchQA 抽 300 条消费级问；另自建 AEBMP（病历 + 循证问题，stage1 约 1,000 问 / stage2 100 问）和 MOEQA（医嘱解释 + 临床追问）。
- **指标：** 客观题 **Accuracy**。开放题由医生/患者盲评：有用、有害、科学共识、专业性、相关、完整、多样、经验支持、偏见；循证场景另报 **证据有效性、可信度、是否虚构引用**。他们还做了自动引用评测 Link-Eval（引用精确率 / 召回、陈述正确性）。
- **结果 / 首张结果图：** Fig. 1 是框架总览，**第一张结果图是 Fig. 2**。Fig. 2a–b：LINS 接 o1-preview 后，6 套公开题准确率分别到 **83.17 / 77.00 / 92.31 / 94.58 / 90.14 / 86.54**（裸模型 PubMedQA* 仅 57.20）。Fig. 2c：同一底座上 LINS 全面压过 MedRAG 和 Clinfo.ai。Fig. 2f：5 名医生评 300 题，有用 94.40% vs 85.67%；误导 1.27% vs 2.27%；完整 94.87% vs 55.07%。后续 Fig. 3：100 名住院医认为 LINS 能帮循证的比例 87.00%，证据有效性 86.41%（比裸模型高约 39 个百分点）；裸模型 3,000 次评里有 1,478 次无效证据，LINS 仅 61 次。
- **一句话：** 医学问答分成「选择题准不准」和「开放题医生觉得有没有用、证据假不假」两套账，RAG 的卖点写在证据有效性上，不写在准确率小数点后。

对你们：Multi-MedCQA 里有血液科子库，说明 **专科题必须医生自建、且最好不把答案公开上网**。开放临床题他们用的是「病历 + 问题 + 多名医生多轴盲评」，和老师要的人标金标准一致。可搬的指标是 **证据有效性 / 引用是否虚构**，不要只报「答得像不像」。

### #2 Pan 等. *JAMA Oncology* 2023. IF ≈ 20–28（Research Letter）

- **Benchmark：** **自建、不公开题库**。Google Trends 2021–2023 美国搜索量最高的 5 个癌种（皮肤、肺、乳腺、结直肠、前列腺）× 每癌种 Top 5 查询 × 4 个 chatbot（ChatGPT-3.5、Perplexity、Chatsonic、Bing AI）= **100 条开放回答**。查询原样输入，每题新开对话。
- **指标：** 已有健康传播量表，**不是自创 Likert**。信息质量 **DISCERN**（1–5）；可理解 / 可行动 **PEMAT**（0–100%）；误导用已发表 5 点量表，**金标准是当时 NCCN 指南**；可读性 **Flesch–Kincaid 年级**；并记录引用了哪些网站。两名作者独立盲评 chatbot 身份，一致率 **95%**。
- **结果 / 首张结果图：** 短文没有独立彩图，**核心结论表就是 Results 的 Table**。总体 DISCERN 中位 5（范围 2–5）；误导分中位 **1（完全无误导）**；PEMAT 可理解中位 66.7%，可行动中位仅 **20%**；年级中位 12.3（大学水平）。ChatGPT 一条引用都没有；另外三家常引 Mayo Clinic、ACS、CDC。
- **一句话：** 肿瘤开放问答不自造分数，用 DISCERN / PEMAT 看「写得清不清、能不能照着做」，再用 NCCN 看「有没有胡说」。

对你们：这是最接近「专科开放 QA」的期刊写法。你们评指南问答时，**误导分应对齐 NCCN / CSCO / EHA 原文**，双人盲评并报一致率。注意：他们测的是患者热搜（症状、什么是某癌），不是 MDT 决策题；准确不等于可行动。DLBCL 治疗问应另加「建议是否可执行 / 是否漏关键分层」。

### #3 Xiong 等. MIRAGE / MedRAG. ACL Findings 2024

- **Benchmark：** **拼盘公开**。MIRAGE 共 **7,663** 题：MMLU-Med 1,089、MedQA-US 1,273、MedMCQA 4,183、PubMedQA* 500（去掉原文给的摘要）、BioASQ-Y/N 618。设定故意贴近真实提问：**零样本、只给问题不给选项去检索（QOR）、再用选项准确率计分**。配套工具 MedRAG：语料（PubMed / StatPearls / 教材 / 维基 / 四库合并 MedCorp）× 检索器（BM25 / Contriever / SPECTER / MedCPT 及 RRF 融合）× 6 个 LLM，41 种组合。
- **指标：** 各子集 **Accuracy ± 标准差**，再报五集平均。对照是「同一 LLM 只做思维链、不检索」。另看检索条数 \(k\) 的缩放，以及金标准段落放在上下文中间会不会被丢掉（lost-in-the-middle）。
- **结果 / 首张结果图：** Fig. 1 只是题库拼盘。**第一张性能结果是 Table 6**：GPT-4 纯思维链平均 **73.44%**；MedRAG（MedCorp + RRF-4 + 32 段）把 GPT-3.5 从约 61% 拉到 **71.57%**（相对提升最高约 **18%**），逼近 GPT-4 不检索。GPT-4 + MedRAG 排行榜平均 **79.97%**。**第一张机制图是 Fig. 3**：考试题上 \(k\) 在 32 以内大致 log-linear；PubMedQA* 常常 \(k=1\) 最好，再加段落反而降。教材 / StatPearls 只帮考试题，**PubMed 是唯一对五集都正贡献的单库**。
- **一句话：** 医学 RAG 问答用现成选择题当尺子，但检索时不许偷看选项；主结论是「检索组合往往比换更大模型更值钱」。

对你们：Part 1 可以按他们的 QOR 来跑——检索阶段不要把 A/B/C/D 喂进去，否则是漏题。Part 2 应像 Table 7 那样做 **语料 × 检索器** 小表（NCCN / CSCO / EHA 单库 vs 合并），不要只报一个总准确率。\(k\) 过大有害，和你们指南切块数量直接相关。

### #4 Chen 等. FinQA. EMNLP 2021（金融，其他领域）

- **Benchmark：** **新建并公开**。11 名财务专家（CPA / MBA 等）在标普 500 年报页上写题，共 **8,281** 问答；每题带 **金标准推理程序**（最多 5 步：加减乘除、比较、表聚合）和支撑事实（哪几句、哪几行）。另请两名外部专家答 200 题当人类上限；众包非专家作对照。
- **指标：** **Execution Accuracy**（程序跑出来的数字对不对）+ **Program Accuracy**（把数字换成符号后，推理式是否代数等价）。作者写明：只看最终数字会高估（蒙对），只看程序会低估（一题多解）。
- **结果 / 首张结果图：** Fig. 1 是样例（从表和正文各取一个数再相减）。**第一张结果是 Table 2**。当时最好系统 FinQANet（RoBERTa-large）执行准确率 **61.24%**、程序准确率 **58.86%**；给金标准检索后执行准确率升到 70.00%。专家人类 **91.16% / 87.49%**，众包非专家 **50.68% / 48.17%**。模型超过外行，但离专家还差一大截。
- **一句话：** 高风险领域问答不但要最终答案对，还要推理步骤可核验；金标准由领域专家写程序，不由模型编。

对你们：医学很难做成「一段可执行代码」，但精神可搬——Part 3 的采分点应是 **可核验的事实/决策步骤**（分期、IPI、一线方案是否写对），等价于他们的 program，而不是「读起来像专家」。他们用专家 vs 众包证明：**外行打分不能当金标准**。

### #5 Sorodoc 等. GaRAGe. ACL Findings 2025（通用 RAG，其他领域）

- **Benchmark：** **新建并公开**。2,366 道长答案问题，覆盖快变 / 慢变 / 静态、热门 / 长尾、公网 + **私有知识库**；检索回来的 **3.5 万余段落由人标「是否相关、是否够用来答」**，并配人写的带引用长答案。证据不足的子集专门用来测拒答。
- **指标：** 相对人写长答案的 **Eligibility**（有没有答到点上）；相对「全部检索段落」的事实性 vs 只相对 **标成相关的段落** 的 **RAF（Relevance-Aware Factuality）**；证据不够时的 **拒答真阳性**；引用相对人标引用的 **P / R / F1**。打分用 GPT-4o 当 judge，但段落相关性和人写答案是人标的。
- **结果 / 首张结果图：** Fig. 1 是带引用的样例。**第一张结果是 Table 2**。最好模型 RAF 大约 **60%**（Nova Pro 60.67，Gemini 1.5 59.43）；GPT-4o Eligibility 最高（92.47）但 RAF 只有 52.88——说明它爱用参数记忆，不严守检索段落。引用 F1 最高约 **58.9%**。证据不够时拒答真阳性最高约 **31%**。快变事实、私有库、相关段落占比低时，RAF 再掉 10–20 个点。
- **一句话：** 开放 RAG 问答不评「总结得漂不漂亮」，评「有没有只用标成相关的段落、证据不够会不会闭嘴」。

对你们：指南 RAG 最该防的就是他们说的 **over-summarise**——把检索噪声和模型记忆混进答案。可对标的三件事：① 引用 F1（引用的 chunk 是不是真支撑这句话）；② 负向题 / 证据不足应拒答或声明不确定；③ 不要用「相对全部检索段落的忠实度」当主指标，那会奖励胡乱总结。LLM 打分可以做附录，前提是 **段落相关性和参考答案先由人锁死**。

## 3. 五篇合在一起，评估可以怎么写

不要再把「问答系统」评成「又刷了一遍 MedQA」。可对外讲的三句话：

1. **有选项的知识题**：公开库 + 准确率；检索时不把选项漏给检索器（#3）。
2. **有指南的专科开放题**：人出题或人选题，双人按指南打「对 / 错 / 误导」，最好再用现成量表看完整性和可执行性（#2）；有 RAG 时单报证据有效性和引用是否可核验（#1）。
3. **病历开放题**：人锁病例事实，人写采分点；主指标是采分点命中，不是 ROUGE，也不是未校准的模型打分（#4 的程序准确率、#1 的医生盲评）。证据不足要会拒（#5）。

本轮刻意没再收 AMIE、MedHELM、HealthBench：那些是问诊、任务拼盘或对话 rubric，不是「一道临床问、一个带证据的答」。
